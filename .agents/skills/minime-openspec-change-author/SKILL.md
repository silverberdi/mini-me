# OpenSpec Change Author
Only create the next roadmap stage after the previous stage is fully closed/archived and the human explicitly advances. Use OpenSpec-native workflows. Proposal states value/non-goals; specs are observable with failure/denial scenarios; design resolves implementation-shaping choices; tasks are small/testable. Never pre-create future active changes.
