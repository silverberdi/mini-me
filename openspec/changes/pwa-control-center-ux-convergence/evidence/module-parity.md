## Runtime ownership

The recursive static import test requires every remaining JS file to be reachable from this one entrypoint and present in the Service Worker static allowlist.

## Post-removal verification

This continuation adds an actual browser→FastAPI Projects onboarding path backed by a disposable canonical service binding and real local Git clone/marker, fixes the form/API field mismatch, adds actual Backlog create through that binding, and adds keyboard roving-tab/focus/reduced-motion coverage. The post-removal consolidated group passed **134 tests, 4 warnings in 98.38s**, including five target viewports, auth/session CacheStorage isolation, listener/bootstrap uniqueness and source-graph checks. A subsequent focused real-Chrome dialog-focus extension passed **1 test in 5.60s**, proving native modal focus is contained and Escape restores focus to the invoker. Two fixture corrections were required: the local onboarding repository now resides under its explicit trusted root and has a verifiable `origin`; the roadmap uses the discovery parser's canonical `key: title (BACKLOG)` syntax. The guard and parser were not relaxed.
