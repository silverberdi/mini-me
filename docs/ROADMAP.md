## Gobierno vigente

Un Issue corresponde a un Change OpenSpec cohesivo y requiere autorización del operador. La admisión FIFO solo actúa dentro del flujo autorizado. No mantener un backlog paralelo en PostgreSQL. El alcance, orden y cierre se obtienen de GitHub y del Change OpenSpec asociado, bajo el contrato v2.0.
